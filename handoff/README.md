# handoff — AniBeat 2.0

- `AniBeat-release.apk` — production release (release-signed keystore `anibeat`, v2+ signing).
- `AniBeat-release.sha256` — SHA-256 of the APK (written by CI at build time).
- `anibeat-sources.zip` — ALL project sources (regenerated by CI on every green build).

Build: GitHub Actions (`gradle assembleRelease`), Gradle 8.14, JDK 21, Android SDK 36.
Stack: Kotlin 2.1 + Jetpack Compose 1.8 (Material 3), Media3 1.7, Room 2.7, DataStore, Hilt,
Coroutines/Flow, Navigation Compose, Coil 3, Lottie 6 — 14-module Clean Architecture.

API — точь-в-точь как сайт: AnimeThemes.moe + AnisongDB (+ malIDs/exact-name fallbacks),
Shikimori (гонка зеркал, shikimori.tv первым) + AniList. Видео — только по кнопке,
одна попытка fallback на второй URL, затем авто-next через 1500 мс (player.tsx).
