# AniBeat для Android

Нативное Android-приложение на Java/Android SDK для прослушивания аниме-музыки из исходного сайта. В проект перенесены основные источники и сценарии сайта:

- AnimeThemes — открытия, эндинги, вставки, обложки и страницы аниме;
- AnisongDB — расширенный поиск и редкие/insert-треки;
- поиск по аниме, треку и исполнителю;
- фоновый проигрыватель с системным уведомлением, очередью, предыдущим/следующим треком;
- избранное, история, плейлисты и офлайн-сохранение;
- настройки 18+, расширенной базы и экономии трафика.

Приложение собрано без Kotlin, Compose, AppCompat и сторонних runtime-библиотек. Это сохраняет небольшой размер release APK и подходит для Android SDK.

## GitHub Actions

Workflow `.github/workflows/release-apk.yml` собирает только подписанный `release` APK, проверяет ограничение 4 MiB и помещает текущий файл в `handoff/AniBeat-release.apk`. Никакой эмулятор, тесты или lint workflow не запускаются.

Для постоянной подписи workflow сначала использует секреты репозитория:

- `ANIBEAT_KEYSTORE_BASE64`
- `ANIBEAT_KEYSTORE_PASSWORD`
- `ANIBEAT_KEY_ALIAS`
- `ANIBEAT_KEY_PASSWORD`

В проект также включён постоянный bootstrap-ключ `signing/anibeat-release.p12`, чтобы сборка не зависела от ручной настройки secrets. Для публичного репозитория рекомендуется заменить его на эти secrets перед распространением APK. Ключ должен оставаться постоянным: это необходимо, чтобы каждый новый APK устанавливался поверх предыдущей версии как обновление. Версия увеличивается автоматически по номеру запуска Actions.
