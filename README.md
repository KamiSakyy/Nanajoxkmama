# AniBeat для Android

Нативное Android-приложение на Java/Android SDK — **полный порт всего функционала сайта** AniBeat:
черная минималистичная тема как на сайте, Material-иконки, Material-карточки, анимации,
уведомление плеера, всё вплоть до последней фичи.

## Функционал (1:1 с сайтом)

- **Главная** — «Трек дня», живая лента Live, перекод периода (Сегодня/Неделя/Всё время),
  быстрые действия (Радио, Опенинги, Эндинги, Офлайн, 18+), новинки, **миксы** (Сёнэн-энергия,
  Эпик и драма, Чилл и романтика, Новая волна, Классика), случайные, текущий сезон аниме,
  **Легенды**, недавние, исполнители, недавно добавленные;
- **Поиск** — дебаунс 380 мс, вкладки Всё/Треки/Аниме/Артисты, недавние запросы, подсказки,
  поиск по-русски через Shikimori, расширенная база AnisongDB («Ещё треки»);
- **Обзор** — годы по десятилетиям, страница года с сезонами и «Слушать весь сезон»,
  лента «Новое» с фильтром по жанрам, ленты OP/ED с пагинацией «Показать ещё»;
- **Страница аниме** — постер, русское название (Shikimori), оценка, тип, жанры, описание,
  фильтры OP/ED/Вставки со счётчиками, версии тем, студии/серии, скачивание всех треков;
- **Страница исполнителя** — аватар, сортировка (Новые/Старые/По аниме), play/shuffle;
- **Медиатека** — избранное, скачанное (офлайн + очередь загрузок с прогрессом),
  плейлисты (создание/переименование/удаление), история;
- **Плеер** — очередь с перестановкой и очисткой, shuffle / repeat (off/all/one),
  ±10 секунд, избранное, скачать, поделиться, «дальше в очереди», видео-режим,
  акцентный цвет из обложки, свайп вниз, мини-плеер с прогрессом;
- **Настройки** — период, 18+, русские названия, расширенная база, экономия трафика,
  предзагрузка следующего трека, формат скачивания, управление хранилищем.

## Источники (как на сайте)

- **AnimeThemes.moe** — опенинги, эндинги, аудио и видео;
- **AnisongDB** — вставки и редкие темы;
- **Shikimori** — русские названия, оценки, описания, жанры (с гонкой зеркал);
- **AniList** — постеры в высоком разрешении, баннеры, акцентные цвета.

## Дизайн

- Монохромная черная тема сайта (`#000` → `#0B0B0C` → `#141416` …), система цветов 1:1;
- **82 Material-иконки** (vector drawables в стиле сайта);
- Material-карточки со скруглениями и ripple-эффектами, tap-scale;
- Анимации: слайд-ап плеера, пилюля сегмент-контрола, shimmer-скелетоны,
  эквалайзер-бары у играющего трека, LIVE-точка, fade-in обложек, кастомные тосты.

Приложение собрано без Kotlin, Compose, AppCompat и сторонних runtime-библиотек —
release APK остаётся крошечным (лимит workflow — 4 MiB).

## GitHub Actions — сборка APK

Workflow `.github/workflows/release-apk.yml` собирает подписанный `release` APK:
1. восстанавливает постоянный ключ подписи (секреты `ANIBEAT_KEYSTORE_*` или bootstrap `signing/anibeat-release.p12`);
2. выполняет `gradle assembleRelease` с автоверсией (`1.0.<run>`);
3. кладёт текущий файл в `handoff/AniBeat-release.apk` (+ `version.txt`, `SHA256SUMS.txt`) и проверяет лимит 4 MiB.

APK обновляется в `handoff/` при каждом пуше — это и есть готовый файл для установки.
